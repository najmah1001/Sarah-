رسالة خاصة — نسخة HTML / CSS / JavaScript
==========================================

الملفات:
- index.html      الصفحة
- styles.css      التنسيق
- script.js       التفاعل (الظرف، زر "لا" الهارب، الأغنية)
- assets/         الصور

طريقة التشغيل:
افتح index.html بأي متصفح مباشرة.

إضافة أغنية:
ضع ملف باسم song.mp3 بجانب index.html — راح يشتغل تلقائيًا
عند فتح الظرف، وبيظهر زر تشغيل/إيقاف بالزاوية.
إذا ما كو ملف، الزر يختفي لحاله.

تغيير الاسم:
افتح script.js وغيّر السطر الأول: var NAME = "مريم";

النشر على GitHub Pages:
ارفع كل الملفات لمستودع، ثم Settings > Pages > Branch: main / root.
